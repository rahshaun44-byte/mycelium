## 2. What Deep Work Is NOT

* **Not "Grind 14 Hours":** Depth is about protected 60–90 minute blocks, not physical exhaustion or masochism.
* **Not "No Tools / No AI":** A single, rigorously specified problem solved with one AI assistant is deep. Five agents rewriting the same HUD in circles is shallow with extra steps.
* **Not Flow as a Vibe:** Flow can occur inside deep work, but the discipline is the block, not waiting for a magical feeling.
* **Not Introversion:** Deep work can happen on a team if the social contract is: *"For these 90 minutes, only this one problem exists."*

## 3. Why Shallow Work Feels Like Progress

Shallow work produces cheap neurological rewards:
* Git status noise
* Formatting another markdown file
* Renaming directories
* Re-checking Tailscale status every 5 minutes

Your brain gets a dopamine checkmark. But the cold reality did not move:
* `ledger.dat` does not exist.
* The school assignment is still unsubmitted.
* The bank balance has not changed.

That is how a day can feel completely full while leaving real-world leverage at zero.
