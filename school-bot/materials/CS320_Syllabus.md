# CS 320: Software Testing, Automation, and Quality Assurance
**Course Prerequisites:** IT 145

## Course Description
Students will apply software engineering testing strategies and practices as part of the software development life cycle, including requirements analysis, verification and validation, and quality management. The creation of unit tests and analysis of various testing approaches will also be covered.

## Course Competencies
- **CS-30415:** Create unit tests using code to uncover errors.
- **CS-30416:** Analyze various approaches to software testing based on requirements.
- **CS-30417:** Apply appropriate testing strategies to meet requirements.

## Core Textbooks
1. *Software Testing: An ISTQB-BCS Certified Tester Foundation Guide* (Brian Hambling et al., 4th Edition, 2019)
2. *Mastering Software Testing with JUnit 5* (Boni Garcia, Packt, 2017)

## Weekly Modules
1. **Module 1:** Role of Testing in SDLC (ISTQB Chapters 1 & 2)
2. **Module 2:** Continuous Integration, Dynamic/Static Testing (ISTQB Chapters 3 & 4)
3. **Module 3:** Requirements & Contact Service Testing (JUnit 5 Chapters 3 & 6)
4. **Module 4:** Task Service Testing, Unit Testing Approach
5. **Module 5:** Appointment Service Testing
6. **Module 6:** Test Strategy, Monitoring, and Control (ISTQB Chapter 5)
7. **Module 7:** Released Escapements and Defects
8. **Module 8:** Software Automation

## Key Focus Areas
- JUnit 5 Unit Testing
- Dynamic vs Static Testing
- SDLC Integration & CI/CD principles
- Requirement-based testing
