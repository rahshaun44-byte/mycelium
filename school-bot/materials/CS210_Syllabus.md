# CS 210: Programming Languages
**Course Prerequisites:** IT 145

## Course Description
Students will develop functional programs that comply with industry regulations and best practices using various programming languages. Special attention will be paid to the importance of developing code that is not only functional, but also secure, efficient, and professional.

## Course Competencies
- **CS-20401:** Utilize various programming languages to develop secure, efficient code.
- **CS-20402:** Design functional programs that comply with industry regulations and best practices.
- **CS-30403:** Write professional, well-documented, and readable code.

## Core Resources
- *zyBooks: Programming Languages*
- Sense Education Tutor Tool
- IDEs: Microsoft Visual Studio, PyCharm Community Edition, Eclipse (Java / C++)

## Weekly Modules
1. **Module 1:** Comparing Programming Languages (zyBooks Ch 1-2)
2. **Module 2:** What’s Bugging You? (zyBooks Ch 3)
3. **Module 3:** Language Syntax & Paradigms (zyBooks Ch 4-5)
4. **Module 4:** Deep Dive Part 1 (zyBooks Ch 6)
5. **Module 5:** Working With Files (zyBooks Ch 7)
6. **Module 6:** Language Specifics (zyBooks Ch 8-9)
7. **Module 7:** Advanced Language Features (zyBooks Ch 10)
8. **Module 8:** Portfolio & Ethics ("What Would You Do?")

## Key Focus Areas
- Cross-language syntax comparison (C++, Java, Python)
- Secure coding practices
- File I/O operations
- Writing professional, readable, documented code
