# QuantumFlex Independent Assessment & Third-Party Evaluation Guide

**Audience:** Third-Party Security Assessors, NVLAP Accredited Laboratories, Government Penetration Testing Teams, and Enclave Auditors  
**Target of Evaluation (TOE):** QuantumFlex Mycelium Enclave (Core C++ Engine v2.5, PQC Immune Daemon, Sentinel Gatekeeper, Amara/Athena API Strata)  
**Standard References:** NIST SP 800-53 Rev 5, OMB M-26-15, NIST FIPS 203, ISO/IEC 18033-2  

---

## 1. Objective and Boundary of Assessment

This guide provides an external evaluator with instructions to independently inspect, build, test, and verify the cryptographic and operational guarantees of QuantumFlex.

### Scope Demarcation:
- **Verified in This Repository**:
  1. Deterministic memory zeroization of ephemeral keys (`OPENSSL_cleanse`).
  2. Strict FIPS 203 fallback policy (fail-closed, no unapproved algorithms or parameter downgrades).
  3. Single-session wire framing validation, fragmentation reassembly, and anti-DoS LRU reassembly boundaries.
  4. Shamir Secret Sharing (GF(256), 3-of-5 threshold) disk state sealing and locked restart enforcement.
  5. Mutual TLS (TLS 1.3) client-certificate Common Name authorization.
  6. Disposable container containment in volatile tmpfs airlock with dropped capabilities.
- **Explicitly Excluded / Requires Separate Accredited Laboratory Testing**:
  1. **CMVP FIPS 140-3 Cryptographic Module Validation**: OpenSSL 3.5.8 default provider executes ML-KEM-768 natively, but CMVP module validation requires testing `fips.so` under approved vendor operating conditions.
  2. **Host Kernel Integrity**: Attacker scenarios where the underlying Linux kernel or host root is compromised are outside the software TOE trust boundary.

## 2. Environment Prerequisites

Evaluators can reproduce all checks in an isolated Fedora 40/41/42 or Debian/Ubuntu container or VM with:
- **Compiler**: GCC 14+ or Clang 18+ (C++20 support)
- **Crypto Engine**: OpenSSL 3.5.0+ (with native ML-KEM-768 support)
- **Policy Engine**: Open Policy Agent (`opa`) CLI v0.68.0+
- **Container Runtime**: Rootless Podman 5.0+
- **Python Runtime**: Python 3.12+ with `pytest`, `fastapi`, `wasmtime`, `httpx`

## 3. Step-by-Step Reproduction Instructions

### Step 1: Clone and Clean Build
```bash
git clone <repository_url> quantumflex
cd quantumflex
cmake -B build_check -DCMAKE_BUILD_TYPE=Release
cmake --build build_check -j$(nproc)
```

### Step 2: Run Formal Rego Policy Verification
```bash
opa test pqc-immune-daemon
opa test sentinel/policies
```
*Expected Outcome: 12/12 and 10/10 tests PASS.*

### Step 3: Run C++ Cryptographic & Framing Invariant Binaries
```bash
./build_check/test_mlkem768
./build_check/test_hybrid_kem
./build_check/test_wire_fuzz_negative
./build_check/test_zeroization
```
*Expected Outcome: All memory zeroization, wire fuzzing, and ML-KEM roundtrip assertions PASS with exit code 0.*

### Step 4: Run Adversarial Failure-Mode Test Suite
```bash
PYTHONPATH=. ./venv/bin/pytest tests/test_adversarial_failure_modes.py -v
```
*Expected Outcome: 12/12 failure-mode tests PASS (verifying slowloris timeout, mTLS CN rejection, empty inventory rejection, cold restart lock, and 401 unauthenticated drops).*

### Step 5: Execute Full Reproducible Audit Bundle
```bash
bash scripts/reproducible_audit_bundle.sh
```
*This command executes the entire verification pipeline, evaluates live socket and database permissions, and writes `AUDIT_BUNDLE_REPORT.txt` with SHA-256 checksums.*

## 4. Formal Verification (F* / EverParse) Alignment Roadmap

For formal verification of the binary wire framing protocol:
1. **EverParse 3D Validator**: Replace handcrafted header unpacking in `src/core/wire_framing.cpp` with a verified C validator generated by EverParse from a formal 3D specification.
2. **State Machine Verification**: Prove that LocalNode state transitions strictly enforce:
   - Sealed restart cannot enter `ACTIVE` without $\ge 3$ valid Shamir shards.
   - Handshake requests (`0x12`, `0x13`, `0x14`) cannot mutate ledger or harvester keys.
   - Denied commands leave state roots strictly unmodified.
