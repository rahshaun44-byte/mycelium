\subsection{QUBO-to-Ising Hamiltonian Mapping and Eigenvalue Verification}

Circuit \texttt{pub\_0\_qaoa} encodes a three-asset binary Markowitz portfolio optimization problem into a Quadratic Unconstrained Binary Optimization (QUBO) objective function over $x = (x_0, x_1, x_2)^{\mathsf{T}} \in \{0,1\}^3$ representing Technology Growth ($x_0, \mu_0 = 0.15$), Energy Sector ($x_1, \mu_1 = 0.10$), and Treasury Bonds ($x_2, \mu_2 = 0.05$), where Qiskit's little-endian bitstring $\vert q_2 q_1 q_0 \rangle$ maps to $x = (q_0, q_1, q_2)$~\cite{qfx_doc}. With risk-aversion parameter $\lambda = 0.5$, exact cardinality budget $B = 2$ active assets, and quadratic penalty weight $A = 1.0$, the classical objective is~\cite{qfx_doc}:
